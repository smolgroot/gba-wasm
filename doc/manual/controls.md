# Controls and Shortcuts

## GBA buttons on the keyboard

| GBA button | Key |
| --- | --- |
| D-pad | <kbd>←</kbd> <kbd>↑</kbd> <kbd>↓</kbd> <kbd>→</kbd> |
| A | <kbd>X</kbd> |
| B | <kbd>Z</kbd> |
| L | <kbd>A</kbd> |
| R | <kbd>S</kbd> |
| Start | <kbd>Enter</kbd> |
| Select | <kbd>Shift</kbd> (left or right) |

Keys work by **position**, not by the letter printed on them. The table uses the US QWERTY labels; on other layouts, use the keys in the same place:

| GBA button | QWERTY | AZERTY | QWERTZ |
| --- | --- | --- | --- |
| A | <kbd>X</kbd> | <kbd>X</kbd> | <kbd>X</kbd> |
| B | <kbd>Z</kbd> | <kbd>W</kbd> | <kbd>Y</kbd> |
| L | <kbd>A</kbd> | <kbd>Q</kbd> | <kbd>A</kbd> |
| R | <kbd>S</kbd> | <kbd>S</kbd> | <kbd>S</kbd> |

Any number of keys can be held at once. Keys are ignored while <kbd>Ctrl</kbd>, <kbd>Alt</kbd>, or <kbd>⌘</kbd> is held, so browser shortcuts keep working.

## Emulator shortcuts

| Key | Action |
| --- | --- |
| <kbd>P</kbd> | Pause or resume |
| <kbd>F2</kbd> | Save state to slot 1 |
| <kbd>F4</kbd> | Load state from slot 1 |

These work on the play screen while a game is loaded. See [Saved Games](./saves.md#save-states) for the other slots.

## Home page

| Key | Action |
| --- | --- |
| <kbd>←</kbd> / <kbd>→</kbd> | Previous or next cover (with the cover flow focused) |
| <kbd>Enter</kbd> | Launch the centred cover |

## Touch

The on-screen buttons map one to one to the GBA buttons. See [Using the touch controls](./play-modes.md#using-the-touch-controls) for multi-touch, sliding, and the D-pad joystick.

| Gesture | Where | Action |
| --- | --- | --- |
| Tap the menu button | Landscape play | Show or hide the actions |
| Tap the splash | Game start | Skip the splash |
| Tap the game | While paused | Resume |
| Drag or swipe | Cover flow | Scroll the covers |

## Not supported yet

- Changing the key bindings
- Game controllers (the Gamepad API)
- Link cable and multiplayer
